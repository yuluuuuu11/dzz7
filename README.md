соответствующее ей название на английском языке (0 – zero, 1 – one, 2 – two
...).

2. Ввод n
3. Проверка условий:
   
   n = 0? вывести "zero"
   
   n = 1? вывести "one"
   
   n = 2? вывести "two"
   
   n = 3? вывести "three"
   
   n = 4? вывести "four"
   
   n = 5? вывести "five"
   
   n = 6? вывести "six"
   
   n = 7? вывести "seven"
   
   n = 8? вывести "eight"
   
   n = 9? вывести "nine"
